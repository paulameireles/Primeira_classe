## Cliente

| Responsabilidades | Colaboradores | Explicação | 
|---|---|
| Conhecer nome, sobrenome e número de registro | | nenhum colaborador. São dados do próprio cliente.
| Guardar os bilhetes comprados | Bilhete |porque o cliente tem uma lista de bilhetes.
| Calcular o total gasto | Bilhete |O cliente não sabe o preço de cada bilhete. Ele precisa perguntar a cada um: “quanto você custa?” (calcularPreco()) e somar as respostas.
| Gerar seu relatório (dados + bilhetes + total gasto) | Bilhete |porque o relatório lista os bilhetes e precisa pedir os dados de cada um.
